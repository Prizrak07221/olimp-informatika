# Олимп.Инфо — подготовка к олимпиаде по информатике

Сайт для тренировки к Республиканской олимпиаде по информатике (Казахстан).
Работает полностью в браузере, без сервера: подходит для GitHub Pages.

## Что внутри

- **18 задач** из шести туров (2-й, 3-й и 4-й этапы, 2024–2026): краткие условия, примеры,
  подзадачи, подсказки по шагам и разборы.
- **Проверка решений на Python прямо в браузере** (Pyodide в Web Worker): тесты по подзадачам,
  вердикты OK / WA / RE / TL, баллы как на олимпиаде.
- **95 вопросов по 13 темам** с объяснениями: сложность, жадность, бинпоиск, ДП, графы, деревья,
  структуры данных, строки, комбинаторика, биты, перестановки, математика, реализация.
  Режимы: по теме, микс, тренировка дня (чаще слабые темы), экзамен на время, работа над ошибками.
- **Теория** — шпаргалки с шаблонами кода.
- **Пробный тур** — три задачи тура и таймер.
- Прогресс хранится в `localStorage`, его можно перенести кодом на другое устройство.

## Насколько решены задачи

| Статус | Задачи |
|---|---|
| Полный разбор (проверен перебором) | Животные в ауле, Площадь таблицы, Учебные группы, Тосқауылдар, Мақсатты MST, Даука и Ханаби, Смена скобок, Ақсерек-Көксерек, Есть контакт |

| Без разбора | Кубик |

## Структура

```
index.html, css/, js/          — сайт
data/content.js                — задачи, вопросы, теория (генерируется)
data/tests/<задача>.json       — тесты для проверки (генерируются)
sol/<задача>.py                — эталонные решения
tools/                         — содержимое, перебор, генераторы, сборка
```

## Как обновить содержимое

Задачи, вопросы и теория пишутся в `tools/content_*.py`. После правок:

```
python tools/run_samples.py      # решения на примерах из условий
python tools/stress.py -n 300    # сверка решений с перебором на случайных тестах
python tools/build.py            # проверка вопросов «что выведет код» + сборка data/
```

`build.py` выполняет код каждого вопроса «что выведет код» и падает, если ответ не совпадает.

Локальный просмотр: `python -m http.server 8765`, затем http://127.0.0.1:8765/
